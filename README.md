# n8n Automation Portfolio

A collection of practical workflow automation projects built with n8n,
AI integrations, APIs, webhooks, and connected business applications.

## Projects
- **[WhatsApp Chat Bot](projects/whatsapp-chat-bot/README.md)** - A WhatsApp chatbot workflow for automated message handling using its configured nodes and integrations.
- **[WhatsApp Chat Manager](projects/whatsapp-chat-manager/README.md)** - A WhatsApp-related automation workflow for the chat management tasks configured in n8n.
- **[AI Support Call Analysis & Assistant](projects/ai-support-call-analysis-assistant/README.md)** - An AI-assisted workflow for support-call analysis and related assistance tasks.
- **[AI Lead Qualification](projects/ai-lead-qualification/README.md)** - An AI-assisted workflow for evaluating leads and supporting follow-up prioritization.
- **[AI Customer Support & FAQ Automation](projects/ai-customer-support-faq/README.md)** - An automation workflow for customer support and frequently asked questions using configured integrations.
- **[AI Business Operations Assistant](projects/ai-business-operations-assistant/README.md)** - An AI-assisted workflow designed to support business operations through its configured integrations.
- **[AI Newsletter Subscription Manager](projects/ai-newsletter-subscription-manager/README.md)** - A workflow for managing newsletter subscription inputs and related automated processing.

## Technologies

- n8n workflow automation
- AI integrations
- REST APIs and HTTP requests
- Webhooks
- JavaScript and JSON
- Connected business applications

## Importing a Workflow

1. Open the desired project folder.
2. Read its README and review the workflow requirements.
3. Import workflow.json into your own n8n instance.
4. Configure your own credentials and resource IDs.
5. Test with sample data before activating the workflow.

## Security

Workflow exports are provided for demonstration and learning.
Configure your own credentials and review resource IDs, URLs,
and node parameters before running imported workflows.
